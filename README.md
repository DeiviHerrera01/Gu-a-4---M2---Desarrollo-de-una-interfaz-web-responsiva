# Pulso Gym

Sitio web responsivo para un gimnasio en Bogotá. Permite consultar clases y planes, calcular el índice de masa corporal (IMC) y simular una inscripción en línea. Es un proyecto integrador de Ingeniería Web I de la UMB.

## Funcionalidades

- Diseño adaptable a móviles, tabletas y computadores.
- Navegación con menú para dispositivos móviles.
- Sección de beneficios, clases y preguntas frecuentes.
- Filtro de clases por categoría: fuerza, cardio y yoga.
- Planes Básico, Plus y Premium, con selector de pago mensual o trimestral.
- Formulario de inscripción con validación en el navegador y selección de plan.
- Calculadora de IMC con una recomendación general.

> La inscripción es una simulación: el formulario no envía ni almacena datos. La calculadora ofrece orientación general y no constituye un diagnóstico médico.

## Tecnologías

- HTML5
- CSS3 (Flexbox, Grid y media queries)
- JavaScript sin dependencias ni frameworks
- Google Fonts: Poppins e Inter

## Cómo ejecutar el proyecto

No requiere instalación ni proceso de compilación.

1. Clona o descarga este repositorio.
2. Abre `index.html` en un navegador.

También puedes abrir la carpeta del proyecto en Visual Studio Code y usar una extensión de servidor local para recargar la página automáticamente mientras editas.
